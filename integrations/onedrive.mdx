Microsoft OneDrive is one of the most widely used cloud storage platforms, and Aflux is building a first-class integration to bring your OneDrive files directly into Bulk Email, E-Signature, and QR Codes — with the same bring-your-own storage model that keeps your documents in your own cloud at all times.

<Info>
**OneDrive integration is not yet available.** The feature is currently in development. You can join the waitlist by emailing [support@aflux.io](mailto:support@aflux.io) with the subject line **OneDrive waitlist**, and the team will notify you as soon as it launches.
</Info>

## What OneDrive Integration Will Do

When the integration launches, connecting OneDrive to Aflux will let you:

- **Browse OneDrive from inside Aflux** — a built-in file picker will let you navigate your personal OneDrive and SharePoint-backed document libraries without leaving the dashboard.
- **Attach OneDrive files to email campaigns** — reference files directly in Bulk Email without uploading copies; recipients receive a trackable link to the live OneDrive file.
- **Send OneDrive PDFs for e-signing** — select a PDF from OneDrive as the source document for a signature request; the completed, signed PDF will be saved back to the originating OneDrive folder automatically.
- **Point QR codes at OneDrive files or folders** — set any QR code destination to an OneDrive item; Aflux resolves the link at scan time so you can swap the underlying file without reprinting the code.

The integration will connect via Microsoft OAuth (the same sign-in flow used by other Microsoft 365-connected apps), requesting access only to the files and folders you explicitly select.
